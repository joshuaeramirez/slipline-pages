Support

Help for SlipLine on Jira Cloud.

Getting help

Email neuralplan@nbpmi.com. We aim to reply within two working days. Please include your site address (yoursite.atlassian.net) and the project key. Please don't send issue contents or screenshots containing personal data unless we ask.

Getting started

No setup is needed. On install, SlipLine reads each project's history, one project at a time, most recently updated first. Open SlipLine in a project's sidebar to see progress; the tabs appear when the project is ready. A project created later is read the first time someone opens its SlipLine page. For one issue, open the issue and choose Date history in its apps.

Common questions

  • "History is still building." Weekly views appear after the first Monday 00:00 UTC that follows install. Summaries then refresh on their own each week.
  • "N restricted issues not included." Issues with a security level are never stored or shown; only the count appears.
  • Some issues are missing. The app sees only the projects and issues its Atlassian app user is allowed to browse.
  • The backfill stopped or stalled. The SlipLine page offers "Run backfill again"; nothing is lost.
  • Removing data. Uninstall the app; see the Privacy policy.
